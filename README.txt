AMMA BIRTHDAY MINI-GAME

FILES
- index.html: the complete birthday game. No Python installation is needed.

RUN ON YOUR LAPTOP
1. Extract the ZIP folder.
2. Double-click index.html. It opens in Chrome or Edge.
3. Tap "Open the next wish" to reveal the five messages.
4. Tap "Play a little birthday tune" for a built-in instrumental tune.

ABOUT THE QR CODES
A QR code scanned on a phone must point to a public website address.
1. Publish this folder using a static website host (for example GitHub Pages or Netlify).
2. Copy the public HTTPS website link.
3. Open the published page, paste the link into the QR section, and click "Create QR for this wish".
4. Repeat on each wish to create a different QR code. The QR opens that exact wish on the website.

MUSIC
The included tune is generated in the browser and does not require an audio file.
If you want a particular song, replace the built-in tune with an audio file you have permission to use.
